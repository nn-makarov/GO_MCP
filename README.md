# GO_MCP — Telegram-бот с инструментами (Go + Groq + MCP)

Telegram-бот на Go, который понимает запросы на естественном языке через
модель Groq и сам решает, когда вызвать инструмент. Инструменты живут в
отдельном MCP-сервере — бот берёт у него список доступных функций,
передаёт их модели, а когда модель просит вызвать инструмент, идёт за
результатом на сервер.

## Как это работает

```
Пользователь → Telegram-бот → Groq (решает: ответить или вызвать инструмент)
                     ↓ если нужен инструмент
              MCP-сервер (/tools, /call) → результат обратно в Groq → ответ
```

На каждое сообщение:

1. Бот запрашивает список инструментов у MCP-сервера (`GET /tools`).
2. Отдаёт сообщение пользователя и инструменты модели Groq (function calling).
3. Если модель решает вызвать инструмент — бот выполняет вызов через MCP
   (`POST /call`), получает результат и передаёт его обратно модели.
4. Модель формулирует финальный ответ, бот отправляет его в Telegram.

Если инструмент не нужен — модель отвечает текстом напрямую.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `joke` | случайная шутка про программистов |
| `greet` | приветствие по имени |

Добавить свой — допишите его в `cmd/mcp-server/main.go`: описание в
`tools()` и обработку в `/call`. Менять бота не нужно, он подхватит новый
инструмент из `/tools` автоматически.

## Запуск

Нужен только Docker.

```bash
cp .env.example .env
```

Впишите в `.env` два значения:

- `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `GROQ_API_KEY` — ключ с [console.groq.com](https://console.groq.com)
  (раздел API Keys, начинается с `gsk_`)

```bash
docker compose up -d --build
docker compose logs -f bot
```

Бот начнёт отвечать в Telegram. Напишите ему «расскажи шутку» — он вызовет
инструмент `joke`; «привет, меня зовут Иван» — вызовет `greet`.

## Запуск без Docker

Нужен Go 1.22+.

```bash
export GROQ_API_KEY=...    # в первом терминале и во втором
# терминал 1 — MCP-сервер
go run ./cmd/mcp-server
# терминал 2 — бот
export TELEGRAM_BOT_TOKEN=...
export MCP_URL=http://localhost:8081
go run ./cmd/bot
```

## Структура

```
cmd/
  mcp-server/   MCP-сервер: список инструментов и их выполнение
  bot/          Telegram-бот: polling, Groq function calling, вызов MCP
```

## Стек

Go 1.22 · Groq API (llama-3.3-70b-versatile) · Telegram Bot API ·
function calling · MCP · Docker Compose. Только стандартная библиотека Go,
внешних зависимостей нет.
